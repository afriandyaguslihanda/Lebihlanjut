# Perbarui foto dan CV

Buka folder `profil` di GitHub pada cabang yang diterbitkan. Pilih **Add file → Upload files**, lalu unggah berkas pengganti dengan nama yang sama persis.

| Berkas | Dipakai untuk |
| --- | --- |
| foto.jpg | Potret utama dan gambar saat tautan portofolio dibagikan |
| tentang.jpg | Foto di bagian Tentang saya |
| cv.pdf | Tombol Unduh CV |

Gunakan JPEG untuk foto dan PDF untuk CV. Untuk potret utama, tempatkan wajah dekat tengah agar tetap terlihat pada layar kecil. Klik **Commit changes**. Website menggunakan berkas baru setelah cabang tersebut selesai diterbitkan.
